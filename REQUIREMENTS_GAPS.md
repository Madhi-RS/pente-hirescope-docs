# HireScope Requirements Gaps, Decisions, and Conflicts

**Updated:** 2026-09-21  
**Purpose:** Record what the latest product requirement added, what still needs a product decision, and which earlier statements it supersedes. The protected `HireScope.md` and `hirescope-mockup-4.html` remain historical sources; current behavior is defined by the phased stories, `website-user-flow.md`, and `PROJECT_WORKFLOW_QA.md`.

## Confirmed Gaps

These capabilities were necessary for the supplied workflow and were missing or incomplete. They are now assigned to stories; no additional product decision is needed to treat the capability as required.

| ID | Area | Current requirement | Existing requirement | Source | Impact | Decision required |
|---|---|---|---|---|---|---|
| GAP-01 | Organisation isolation | Every recruitment record/action is organisation-owned and cross-organisation access/association is denied | Role scope existed without a complete organisation boundary | New product requirement | Prevents tenant data leakage | No; implement IAM-03, AUTH-03, OPN-01/02/05 |
| GAP-02 | Opening configuration | Configuration is per opening/version, persisted, retrieved, validated, and isolated | Only FairPack/pre-screen configuration existed; organisation-global ambiguity remained | New product requirement | Different openings can run different workflows safely | No; implement OPN-05 |
| GAP-03 | Candidate-first intake | Required candidate data/résumé must be collected before pre-screen analysis or rejection | Minimum interest/manual rules could decide before résumé collection | New product requirement | Reorders intake and prevents early rejection | No; implement CAN-01 |
| GAP-04 | AI résumé pre-screen | Extract facts, compare criteria, explain recommendation/ranking where configured, and preserve immutable versions | Résumé parser/analysis was deferred/out of scope | New product requirement | Adds advisory pre-screen evidence | No; implement CAN-02 |
| GAP-05 | Résumé consistency | Flag supported cross-field discrepancies with cautious language/evidence | No discrepancy workflow | New product requirement | Gives HR verification cues without dishonesty claims | No; implement CAN-02 |
| GAP-06 | HR pre-screen decision | HR reviews all pre-screen evidence, accepts/disregards recommendation, comments, and decides | Rule outcome could create an invitation | New product requirement | Makes human decision authoritative | No; implement CAN-03 |
| GAP-07 | HR-gated test link | Assessment link is generated only after HR qualification | Qualified rule result could issue link automatically | New product requirement | Prevents AI/rule-only progression | No; implement CAN-03/IAM-02 |
| GAP-08 | Readiness page | Dedicated configured environment/time/audio/network acknowledgement and final confirmation before start | Only voice consent/mic check existed | New product requirement | Reduces avoidable assessment failure | No; implement ASM-02 |
| GAP-09 | Interruption options | Interruption must offer Submit Test and Submit Grievance | Grievance-only inactivity flow | New product requirement | Restores applicant choice | No; implement ASM-05 |
